# 调候用神 —— 寒暖燥湿先于扶抑

本文件是取用神的**第一道前置关**：命局寒暖燥湿偏颇时，调候为急，压倒扶抑与格局（滴天髓《论用神配气候得失》：寒暖燥湿偏颇时，"旺衰、格局皆已不重要，调候为急是首要原则"）。取用顺序：**先过本文件判调候 → 再走 [geju-yongshen.md](geju-yongshen.md) §3 定扶抑用神**。

## 1. 总则

- **调候为急**："天道有寒暖，发育万物……人道得之，不可过也"（滴天髓）——命局过寒过暖、过燥过湿，先解气候之偏，再谈日主强弱与格局。
- **判据触发**：出生月份（冬生/夏生）+ 命局火水多寡。触发寒暖偏颇时，**调候用神优先于扶抑用神**。
- **两套用神并存**：调候用神（气候）+ 扶抑用神（身强身弱）不是二选一，而是**先后**：先调候解偏，后扶抑平衡；能兼顾者上格。
- 调候体系源出《穷通宝鉴》（晚出总结书）与滴天髓寒暖燥湿论，与渊海子平体系并存——引用时注明出处，不与渊海子平断律冲突（仲裁见 [arbitration.md](arbitration.md)）。

## 2. 四态判据

| 态 | 判据 | 调候方向 |
|---|---|---|
| **寒** | 冬生（亥子丑月）+ 火弱水旺 | 喜火暖局（丙=太阳，丁=灯烛）；**冬水冻木/冻金，不作喜神** |
| **暖** | 夏生（巳午未月）+ 火旺水弱 | 喜水润局（壬=江河，癸=雨露） |
| **燥** | 戌未月土燥 + 火土旺 | 喜水滋润 |
| **湿** | 辰丑月水湿 + 水旺 | 喜火燥暖 |

**判读顺序**：先看月份定寒暖基调，再看原局火水数量定偏颇程度；火水皆有根气（藏干算）则偏颇缓，一者无根则偏颇急。

## 3. 十干调候要点（穷通宝鉴精简）

| 日干 | 冬月（亥子丑） | 夏月（巳午未） | 要点 |
|---|---|---|---|
| 甲木 | **丁火不可少，非丙无发生**（"寒木向阳"）；身弱借比肩，见寅字最妙 | 癸水润局+庚金劈甲 | 丑月"先庚后丁，乏庚略可，乏丁无用"；**最忌壬癸透干水局** |
| 乙木 | 丙火解冻（藤萝喜阳） | 癸水润+火 | 冬乙木寒，向阳为要 |
| 丙火 | 壬水调候（冬火宜水既济） | 壬水为要（夏火太炎） | 丙火不论冬夏皆重壬水 |
| 丁火 | 甲木引丁（燎原须木） | 庚金劈甲引丁+癸水 | 丁火冬生喜甲木助焰 |
| 戊土 | 丙火暖土（冻土不生） | 癸水润+丙火 | 冬戊土寒，先暖后润 |
| 己土 | 丙火暖+甲木疏 | 癸水润 | 冬己土同戊 |
| 庚金 | **丁火暖金**（金寒喜炼，丁火锻之） | 壬水洗金+丁火锻 | 冬庚金"金寒火暖" |
| 辛金 | 丙火暖（珠玉喜阳）+壬水洗 | 壬水洗+己土埋防 | 冬辛金喜丙 |
| 壬水 | 丙火暖（冬水寒,独喜丙） | 庚金发源+戊土堤防 | 冬壬水通河,喜丙暖 |
| 癸水 | 丙火暖（雨露喜阳） | 辛金发源 | 冬癸水寒,喜丙丁 |

## 4. 调候与扶抑冲突时的取舍

1. **寒暖燥湿偏颇 → 调候第一**：如冬生身弱木命，扶抑要水（印），但冬水冻木——**弃印取火**（2006-01-25 男命实证，见 §7）。
2. **调候用神与扶抑用神方向一致** → 上格，两者同取。
3. **偏颇不重（火水有根气、月份不极端）** → 以扶抑为主，调候为辅。
4. 取舍必须**注明弃用之理**（"弃印取火，因冬水冻木"），不许只报结论。
5. 行运/流年断语按调候喜忌执行：喜火者行火运吉、水运（尤其冬水）慎。

## 5. 行运与方位

- 喜火者：宜东南木火之地，忌西北水冷之地；喜水者反之。
- 方位补益属弱证据（文化参考），报告中标注。

## 6. 批判标注

- 调候为《穷通宝鉴》体系（晚出总结书），与渊海子平/三命通会并存；同一盘两体系取用不同属正常，断语注明来源。
- "冬水冻木""湿木无焰"等为体系内类比语言，非气象学断言。
- 调候断语同样受五大未证假设约束（piping-guide §1），报告局限小节注明。

## 7. 工作示例（2006-01-25 男命：乙酉 己丑 甲寅 甲戌）

- **调候判**：丑月（冬末）寒木，原局火不透干但有根（寅中丙、戌中丁），水仅丑中癸——寒偏颇，调候为急。
- **调候用神：火（丙丁）**；扶抑（身弱）本应喜印（水），但冬水冻木——**弃印取火，比肩（木）帮身为辅**。
- **喜忌**：喜火、木；忌金（官杀）、土（财）、水（冬水最忌）。
- 命例佐证：穷通宝鉴丑月甲木三例（lifan.md）——水局不贵、癸水伤丁贫贱。
- **翻案教训**：初版按扶抑"喜水（印）第一"被实证否定——取用必须先过调候关（本文件），再谈扶抑（已入 reports/_lessons.md）。
