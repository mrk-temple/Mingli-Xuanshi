## 2. 小阿卡纳：四花色主题

| 花色 | 英文 | 元素（本 skill 五行映射） | 主题关键词 |
|---|---|---|---|
| 权杖 | Wands | 火（→火） | 行动、激情、意志、创造力、事业冲劲 |
| 圣杯 | Cups | 水（→水） | 情感、关系、直觉、潜意识、爱 |
| 宝剑 | Swords | 风（→金，版本声明见 tarot-guide §5） | 思想、理智、沟通、冲突、真相（偏冷/锋锐） |
| 星币 | Pentacles | 土（→土） | 物质、金钱、身体、工作、稳定 |

单张读法 = 花色主题 + 位阶/角色骨架（§3/§4），如"圣杯 3"= 情感领域的初结果实与协作；"宝剑 9"= 思维领域的焦虑与噩梦。

## 3. 数字位阶通用骨架（Ace-10）

| 数字 | 通用主题 |
|---|---|
| Ace(1) | 新开始、纯粹潜力的种子 |
| 2 | 平衡、二元、结合或抉择 |
| 3 | 成长、初结果实、协作 |
| 4 | 稳定、结构、休整 |
| 5 | 冲突、动荡、挑战、失落 |
| 6 | 和谐、修复、给予与获得 |
| 7 | 评估、坚持、内省 |
| 8 | 行动、移动、掌控（花色分化：权杖8=快进，宝剑8=束缚，圣杯8=离开，星币8=技艺打磨） |
| 9 | 接近完成、满足或焦虑（圣杯9=愿望达成，宝剑9=噩梦焦虑） |
| 10 | 完成、满溢、终结与轮回 |

## 4. 宫廷牌四角色

| 角色 | 英文 | 含义 |
|---|---|---|
| 侍从 | Page | 学徒、消息、好奇心、学习的开端 |
| 骑士 | Knight | 行动、追求、冲劲、极端化（该花色的"行动者"） |
| 王后 | Queen | 内在掌控、滋养、成熟的阴性能量 |
| 国王 | King | 外在掌控、权威、成熟的阳性能量 |

宫廷牌常读作"人物"：出现时可指问者自己、他人，或该元素特质的成熟度（侍从=新手、国王=统御）。

## 5. 组合读法速记

- 同花色 ≥3 张：该元素领域主导（权杖=行动导向、圣杯=情感驱动、宝剑=思维交锋、星币=务实落地）。
- 同数字 ≥2 张：位阶主题被强调（如多张 7：多评估、勿冒进）。
- 大阿卡纳 ≥3 张：人生主题级事件，解读从"具体事务"升到"人生阶段"。
- 逆位占比 ≥一半：整体能量偏"内在化/受阻"，建议类解读加重"先清理内在"的方向。
