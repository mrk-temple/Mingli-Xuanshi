## 1. 断卦总则

- 先复述脚本输出（本卦/互卦/变卦/动爻/体用/生克），再解读——**事实与解读分开**。
- 结论必须给出推理链：因为体用生克如何、旺衰如何，所以吉凶倾向如何。禁止武断断言（"必成大业"这类）。
- 本卦看当下，互卦看过程，变卦看结果；动爻是事情的关键节点。

## 2. 体用生克的深化

- 脚本已输出基础结论（用生体吉/用克体凶/体生用泄/体克用费力/比和平），解读时结合旺衰修正：
  - 用生体但用卦休囚 → 助力有限；体旺则凶小。
  - 用克体但体旺相 → 有惊无险；体休囚 → 受制明显。
- 变卦五行：变卦的五行定最终趋势，互卦五行看中间过程。

## 3. 按事项类别断

| 事项 | 关注点 |
|---|---|
| 求财 | 用卦与体卦的生克、财爻旺衰 |
| 婚姻 | 体用比和主和顺；用克体主不合 |
| 事业/功名 | 体旺用生主晋升；体生用主操劳 |
| 疾病 | 用克体不利，看旺衰辨轻重 |
| 出行 | 用生体利行；用克体不利行 |
| 失物 | 看用卦方向与动爻位置，比和易寻 |
| 应试 | 体旺为佳，忌用克体 |

表内只是常用方向，具体仍以生克 + 旺衰 + 卦辞爻辞综合断。

## 4. 旺衰与外应

- **旺衰**：以当日干支五行对照卦中五行——当令（月建日辰同五行）为旺，休囚死绝为衰。旺者力大，衰者力小。日辰信息由用户在对话中提供或另行查询，不要编造。
- **外应**：起卦时周围发生的事（鸟叫/器物/他人言行）可作为补充信号，**仅在卦象不明时参考**，并在报告中注明"外应：____"。

## 5. 不确定性处理

- 体用不分（无动爻）或外应冲突 → 如实说明"卦象不明"，不强行解读。
- 一句话结论必须能说清推理依据；说不清就说不确定。
- 免责：命理内容仅供娱乐参考；涉及医疗、投资、法律等领域的建议一律不写。
