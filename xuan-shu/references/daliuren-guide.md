## 1. 断课总则

- 先复述脚本输出（天地盘/四课/三传/课体/贵神），再解读——事实与解读分开。
- 断课以**三传 + 课体 + 六亲生克**为主线：初传看起因、中传看过程、末传看结果。
- 结论带推理链："因初传官鬼克日、末传子孙制鬼，故此事初难后解"。
- 大六壬细节繁复（神煞、年命等不在本 skill 脚本范围），断课只用脚本输出的要素，不自行加装神煞。

## 2. 三传的读法

- **初传（发用）**：事之始、当前、起因。
- **中传**：事之中、发展过程。
- **末传**：事之终、结局。
- **吉凶主线**：
  - 三传顺生（初生中、中生末）主顺畅；逆克（初克中、中克末）主阻滞。
  - 传生干（三传六亲生扶日干）吉；传克干（官鬼克日）凶；初传克日主事发即不利。
  - 初末相冲/相刑、传落空亡 → 主虚、主变、主不成。
- 脚本已输出每传六亲（以日干五行为"我"），直接引用。

## 3. 课体吉凶主题

| 课体 | 主题惯例 |
|---|---|
| 元首课 | 上制下、臣忠，主顺利正大，多吉 |
| 重审课 | 下犯上，主反复、宜详审，事多曲折 |
| 知一课 | 主疑惑、进退不一，宜专一不二 |
| 涉害课 | 主历经艰辛、迟滞有害；见机（孟）主远滞、先难后易 |
| 遥克课 | 主远、隔阂、外来——蒿矢被动、弹射主动 |
| 昴星课 | 主阴私、暗中；虎视主动宜速，冬蛇掩目宜伏藏 |
| 别责课 | 主责己、别求、另谋出路 |
| 八专课 | 主专一独断，亦主私情之事（传统措辞，现代只作"专注/纠缠"参考） |
| 伏吟课 | 主伏而不动、静守、迟缓 |
| 返吟课 | 主反复、动荡、折回、事多变 |

课体定"事之性质"，三传定"事之走向"：两者合读（如"重审课 + 末传生干"= 曲折而终有成）。

## 4. 六亲与贵神天将

- **六亲**（脚本已按日干标注三传六亲）：父母=文书/长辈/庇荫、兄弟=同辈/分耗、子孙=喜悦/制鬼/解忧、妻财=财物/利益、官鬼=压力/官非/疾病。以日干为"我"。
- **贵人十二天将**：贵人=得助、螣蛇=虚惊口舌、朱雀=文书消息、六合=和合、勾陈=田土迟滞、青龙=喜庆财帛、天空=虚诈落空、白虎=凶伤威猛、太常=宴会衣禄、玄武=盗贼暗昧、太阴=阴私、天后=阴私恩泽。断事时只作修饰（如"朱雀临三传主文书之应"），不作吉凶主干。
- 贵神天将不可单凭断吉凶（与 shensha-suiyun 的神煞原则一致）。

## 5. 旬空与旺衰

- **旬空**（脚本已输出空亡二支）：三传落空主"虚、暂不应"，出空填实方应。
- **旺衰**：以月将（中气）所值季节定三传五行旺相休囚死（与梅花/六爻同一张表，systems-map §3），旺者力强、衰者力弱——传虽吉而衰，减等断。
- 空与衰都标"体系内推演"，不写"必"。

## 6. 断课流程与推理链格式

1. 复述脚本输出。
2. 确认所问事项（大六壬一课一问）。
3. 读课体（事之性质）→ 读三传（起因/过程/结果）→ 看传干生克（六亲）→ 看贵神天将修饰 → 看空亡旺衰修正。
4. 结论：吉凶倾向 + 应期提示（出空/当令之时，标"体系内推演"）。
5. 课式不明（三传互相矛盾/课体与事项无法对应）时如实说"课象不明"，不硬断。
6. 免责：仅供娱乐/文化参考，不构成医疗、投资、法律建议。

## 7. 存疑清单与实现选择

脚本按以下选择实现（均为通行说，与《六壬大全》核对过）：

1. **涉害深浅计数**：采用主流法——上神顺行归本家，数"途中被上神所克之地支"（异说"涉归本家/数受克者"未采用）。
2. **八专日**：五日——癸丑、甲寅、丁未、己未、庚申（干寄宫=日支且六十甲子同位之日）；八专日只论上下克、不看遥克（六壬大全卷七）。
3. **八专取传**：阳日干之阳神连身顺数第三位、阴日支之阴神（第四课上神）连身逆数第三位，中末俱取干上神（六壬大全卷七原文，已核实）。
4. **别责**：四课不备（一课=四课 或 二课=三课，四课只得三课）且无克无遥；阳日取干合神之上神、阴日取支三合前一位之上神，中末俱取干上神。
5. **返吟无克**：初传取驿马支本身（另有取驿马所临上神者，未采用）。
6. **贵人昼夜**：占时卯至申为昼、酉至寅为夜（细分到时刻的流派未采用）。

⚠️ 常见流传课例表中"克/贼"方向常有误标：本脚本按标准定义"上克下曰克、下贼上曰贼、贼课优先"实现，与部分二手讲义的手工课例可能不一致——遇到分歧以定义与《六壬大全》原文为准，并在报告中注明。
