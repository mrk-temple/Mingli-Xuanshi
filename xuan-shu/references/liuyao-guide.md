## 1. 断卦总则

- 先复述脚本输出（卦名/宫/世应/六爻六亲六神/动变/旬空月破/旺衰），再解读——事实与解读分开。
- 断卦顺序（增删卜易惯例）：取用神 → 看用神旺衰（月建日辰）→ 看原忌仇神 → 看世应关系 → 看动爻变爻 → 综合断吉凶与应期。
- 结论必须带推理链："因用神妻财爻临月建旺相、得子孙动爻生扶，故求财之事倾向有成"。
- 不动无占、一卦一问：所问事项不明确时先问清，再取用神。

## 2. 取用神（第一关键）

| 所占之事 | 用神 |
|---|---|
| 求财、财物、物价；男测感情/婚姻 | 妻财爻 |
| 官运功名、上级、诉讼官事、疾病灾祸；女测感情/婚姻 | 官鬼爻 |
| 父母长辈、房屋田产、文书契约、车辆、学历、单位 | 父母爻 |
| 兄弟姊妹、朋友同辈、合伙人、竞争对手 | 兄弟爻 |
| 子孙晚辈、徒弟、医药、僧道、六畜、喜悦消灾 | 子孙爻 |
| 问自己、我方 | 世爻 |
| 对方、所测对象的环境 | 应爻 |

细化惯例：测病官鬼=病、子孙=医药；测考试父母=成绩文书、官鬼=名次；测出行世=出行人、应=目的地。取用神错则全卦错——先与用户确认所问事项再取。

## 3. 用神旺衰与生克

- **旺相休囚死**（脚本已按月建标注每爻）：旺（爻五行=月建）> 相（月建生爻）> 休（爻生月建）> 囚（爻克月建）> 死（月建克爻）。
- **日辰为第二基准**：爻值日辰（脚本标"值日辰"）以旺论；日辰克爻则衰。口诀地位："月建为提纲，日辰为主宰"。
- **生克冲合**：动爻/日辰月建对用神的生（助）、克（损）、冲（动散）、合（绊住/成局）逐项过——月建日辰对用神的生克是吉凶主干。
- 用神旺相 + 得生扶 → 吉；用神休囚死 + 受克 → 凶；旺衰两可时如实说"两可"，给区分条件（如"看日辰是否帮扶"）。

## 4. 世应与动变

- **世应**：世=我，应=对方/环境。世应生克关系定事之顺逆：应生世吉、世生应耗、应克世逆、比和则平。
- **动爻**：动爻为事之机；动爻生克用神、世爻是断卦重点（动爻生用神吉、克用神凶、动而冲合用神主变动）。
- **变爻**（脚本已输出变爻干支六亲，以本卦宫为"我"）：动爻化出变爻，看变爻对动爻/用神的生克——回头生（变爻生动爻）吉、回头克凶；化进神/化退神（同五行阴阳顺逆）主进退。
- 多爻乱动时先看动爻与用神、世爻的直接生克，再看其余；无动爻时以月建日辰与用神关系为主（静卦看旺衰）。

## 5. 原神忌神仇神

| 用神 | 原神（生用神） | 忌神（克用神） | 仇神（克原神） |
|---|---|---|---|
| 父母 | 官鬼 | 妻财 | 子孙 |
| 兄弟 | 父母 | 官鬼 | 妻财 |
| 子孙 | 兄弟 | 父母 | 官鬼 |
| 妻财 | 子孙 | 兄弟 | 父母 |
| 官鬼 | 妻财 | 子孙 | 兄弟 |

生克链：生 父母→兄弟→子孙→妻财→官鬼→父母；克 父母→子孙→官鬼→兄弟→妻财→父母。用神弱时看原神是否有力（原神旺且动 → 有救），用神旺时看忌神是否来克。

## 6. 旬空月破的用法

- **旬空**（脚本已标）：爻落空亡主"暂不应/虚而不实"，出空填实（冲空/值日）后方应；动爻旬空待出空，静爻旬空多主无力。
- **月破**（脚本已标）：爻逢月破主当月无力、事有阻；出月不破后复起；月破之爻值日辰合扶可解。
- 空破都是"状态标注"不是"必凶"：须结合用神/动变综合断，标注"因空/破而暂缓"而非"因此必败"。

## 7. 断卦流程与推理链格式

1. 复述脚本输出（六爻全表）。
2. 确认所问事项 → 取用神（写"用神取 X 爻，因所问为求财"）。
3. 用神旺衰（月建+日辰+动爻生克，逐项说）。
4. 原忌仇神（有无救应）。
5. 世应关系 + 动变（回头生克/进退）。
6. 结论（吉凶倾向 + 应期提示：空破出空月、动爻值日等，标"体系内推演"）。
7. 卦象不明（用神两现互相矛盾/动变复杂难断）时如实说"卦象不明"，不硬断。
