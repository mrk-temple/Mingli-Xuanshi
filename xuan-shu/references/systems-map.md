## 2. 各线定位与确定性边界

- **命理线（八字）**：确定性到"排盘+大运"为止（paipan.py）；旺衰/格局/用神是"规则+裁量"（判据在 geju-yongshen，收敛规则在 arbitration）；岁运应期是体系内推演（yingqi）。**本线内容与 yixue-mingli 技能同源**，移植自其 references 全套——同一盘面在两 skill 下断语应一致。
- **纳甲线（六爻）**：确定性到"装卦"为止（起卦→卦宫→世应→纳甲→六亲→六神→动变→旬空月破→旺衰→伏神，全部由 liuyao.py 计算）；取用神与吉凶推断是规则+裁量（liuyao-guide）。流派分歧（字背阴阳/变爻六亲归属）已按主流在脚本显式声明。
- **六壬线（大六壬）**：确定性到"三传"为止（月将→天地盘→四课→九宗门发传→贵神，全部由 daliuren.py 计算）；断课是规则+裁量（daliuren-guide）。九宗门是歧义高发区，脚本按通行规则实现并在输出标注课体。
- **掌诀线（小六壬）**：六宫轮转算法完全确定（xiaoliuren.py，古法三步重锚）；断辞为通行本（个别字词版本差异已注明）。**注意：小六壬与大六壬仅共享"六壬"之名，术理无传承关系**——不要把两者混为一谈。
- **梅花线**：起卦装卦完全确定（qigua.py）；断卦为体用生克+旺衰（duangua-guide）。
- **西占线（塔罗）**：抽牌完全确定（tarot.py，密码学随机+可复现 seed）；牌义与解读全部是语义层（tarot-guide/tarot-meanings），**塔罗与易学体系无本源关系**，元素对应（权杖=火、圣杯=水、宝剑=风→金、星币=土）是后天 syncretic 映射，引用时声明版本。

## 3. 共享公理层：干支、五行、八卦、节气

- **干支纪时**：scripts/common.py 提供日干支（儒略日 mod 60）、月建（太阳视黄经十二节）、时干支（五鼠遁）——liuyao/daliuren 共用，与 paipan.py 同一套公式，保证跨线干支一致（同一公历时刻在任何线上得到同一年月日时干支）。
- **五行生克**：木→火→土→金→水→木；木克土、土克水、水克火、火克金、金克木。六爻六亲、梅花体用、八字十神、六壬六亲全部建立在这套生克上——这是"易学体系"的真正公约数。
- **八卦与先天数**：乾1兑2离3震4巽5坎6艮7坤8（报数/时间起卦取卦用先天数）；三画经卦五行：乾兑金、离火、震巽木、坎水、艮坤土。
- **节气**：立春分年柱、十二节分月柱（paipan.py / common.py 同一近似算法，±15 分钟精度）；月建以节气月为准，不用公历自然月。
- **旺相休囚死**：当令者旺、令生者相、生令者休、克令者囚、令克者死——梅花断卦与六爻断爻共用同一张旺衰表。

## 4. 跨体系组合与互证

- 同一所问事项（如"今年事业如何"）可走多线：八字看岁运框架 → 六爻/梅花看此事一卦 → 塔罗看心态与行动。**组合时各线独立成章，最后互证**：只有多条线指向同一倾向才写"互证"；互相矛盾时如实呈现矛盾，不强行统一（见 yijing-yili.md 的"内部矛盾实例"先例）。
- 互证格式："八字断……；六爻卦象……；两线互证/相抵"——注明每线依据，不写"多线一致所以必应"。
- 同一公历时间的干支在所有线间一致（common.py 保证），这是跨线互证的技术前提。

## 6. 求真底线（全体系通用）

1. **一切断语可溯源**：脚本输出是事实，断语必须给出推理链与出处（哪条规则、哪部书、哪个 reference）。
2. **批判必写**：每次报告含"体系局限"小节（未证假设 + 反证），依据 piping-guide。
3. **不做断言式预言**：不用"必/定/绝"；吉凶倾向用体系内规则语言（"多有/恐/倾向"）。
4. **免责必写**：仅供娱乐/文化参考，不构成医疗/投资/法律建议。
5. **随机性公开**：塔罗/模拟摇卦等随机环节说明随机来源，可用 seed 复现；占筮有效性前提未证（piping-guide §1 数决定论），如实说明。
